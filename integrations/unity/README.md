# Unity / Tuanjie integration (early)

Add this directory as a local package in Package Manager. In the Editor, set the RenderDocX executable under **Tools > RenderDocX**. Open a saved `.rdc`, open the workspace, or choose **Connect current Editor** to look for the current process among local RenderDoc targets. Load RenderDoc through the Editor's supported integration first; RenderDocX will not inject into the running Editor or take over a busy client. Capture notification and opening are handled by the connected workspace. Connection and capture have not yet been validated with Unity or Tuanjie.

`RenderDocX.GpuCapture.TryBegin(out var capture)` optionally wraps Unity's experimental `ExternalGPUProfiler` API. Call on the main thread around appropriate rendering work and dispose the returned scope in `finally` or a `using` statement. `IsAttached` can also indicate a profiler other than RenderDoc. The scope does not load RenderDoc, ensure a frame is captured, choose a destination, or automatically open the result. Use Unity's built-in RenderDoc integration for the Editor's Game/Scene view; its operation is subject to the engine's supported graphics APIs and platforms.

The package targets the documented Unity 2020.3 API surface. Installation, compilation and handoff construction have been checked in an isolated Unity 2022.3 Editor. Tuanjie compatibility depends on its actual API and engine version and has not been established. No Unity Player, GPU, or capture-flow validation has been performed. On Windows, `scripts/test-unity.ps1 -Editor <Unity.exe> -Project <disposable-project>` repeats the package installation and Editor smoke checks; it adds test assets and installs this package into the specified project, so use a fresh disposable project.
